# Etrair Jira–Codebeamer Customization

Repository for the Etrair Jira–Codebeamer customization.

## Project status

The integration flow, API interactions, and widget behavior are still in analysis and design. Record and agree on those decisions before implementation begins. This repository currently contains project governance only; implementation scope has not been committed.

## Development workflow

1. Capture a change as a GitHub issue with its goal and acceptance criteria.
2. Discuss and record design decisions before implementation.
3. Create a short-lived branch from `main` for each issue.
4. Submit a pull request to `main`; describe the change, validation, and version impact.
5. Merge only after the change is reviewed and its issue is linked.
6. Create a version tag when a release is ready.

See [CONTRIBUTING.md](CONTRIBUTING.md) for branch, commit, and version conventions. See [CHANGELOG.md](CHANGELOG.md) for release notes.
