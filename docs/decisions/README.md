# Design decision records

Store accepted decisions that affect the integration flow, API contract, widget behavior, architecture, security, or release compatibility here.

Use one file per decision, named `NNN-short-title.md`, with an incrementing number.

## Suggested structure

```markdown
# NNN. Decision title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD

## Context
What question needs a decision, and what constraints apply?

## Options considered
What reasonable alternatives were considered?

## Decision
What was selected, and why?

## Consequences
What changes for users, implementation, operations, or future decisions?
```

Do not add a decision record until the decision has actually been discussed. Link related GitHub issues and pull requests.
